# Thurston-Alpine
## GitHub Pages structure

Keep the file structure exactly as shown below when uploading to GitHub:

```text
thurstonum-alpine/
├── index.html
├── gallery.html
├── styles.css
├── script.js
├── README.md
└── assets/
    ├── banner.png
    ├── logo-dark.png
    ├── logo-light-soft.png
    ├── churwalden.jpg
    ├── alps-01.jpg
    ├── alps-02.jpg
    ├── group-portrait.jpg
    ├── riding-01.jpg ... riding-08.jpg
    ├── student-1.jpg ... student-4.jpg
    └── training-board.jpg
```

**Important:** the `assets` directory must remain a directory named `assets` in the repository. Do not move its contents into the repository root, because the website references files using paths such as `assets/banner.png`.
