# Thurston Alpine — Public Test Demo

This is the **privacy-safe public test version** of the Thurston Alpine website.

## Public test rules

This repository intentionally does **not** contain:

- the instructor's personal name
- professional certification/qualification details
- personal telephone number
- personal email address
- production booking/contact details

Those details are kept in a separate private production copy and should not be added to this public test repository until the site is approved for launch.

## GitHub Pages structure

Keep the file structure exactly as shown below when uploading to GitHub:

```text
thurstonum-alpine/
├── index.html
├── gallery.html
├── styles.css
├── script.js
├── README.md
└── assets/
    ├── banner.png
    ├── logo-dark.png
    ├── logo-light-soft.png
    ├── churwalden.jpg
    ├── alps-01.jpg
    ├── alps-02.jpg
    ├── group-portrait.jpg
    ├── riding-01.jpg ... riding-08.jpg
    ├── student-1.jpg ... student-4.jpg
    └── training-board.jpg
```

**Important:** the `assets` directory must remain a directory named `assets` in the repository. Do not move its contents into the repository root, because the website references files using paths such as `assets/banner.png`.

## Intended use

This version is for public GitHub/GitHub Pages testing on desktop and mobile while the design is being refined.
